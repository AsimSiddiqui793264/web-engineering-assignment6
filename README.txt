WEB ENGINEERING - LAB 06
Exercise: Creating a Colorful Table with Images

PROJECT FILE
- index.html: Complete HTML5 and Bootstrap 5 assignment.

HOW TO RUN
1. Extract the ZIP file.
2. Open the Web_Engineering_Lab_06 folder in VS Code.
3. Open index.html.
4. Run it with Live Server, or double-click index.html to open it in a browser.
5. Keep an internet connection enabled because Bootstrap CSS/JavaScript and the sample images use CDN/online URLs.

REQUIREMENTS COVERED
- HTML5 document structure
- Bootstrap 5 CSS CDN
- Responsive table using table-responsive
- Four tourist-place rows
- Image in every row with img-thumbnail
- Name and short description in every row
- table-primary, table-success, table-warning, and table-danger row classes
- Responsive image sizing and alt text

NOTE
The images are loaded from online image URLs. If an image does not load, check the internet connection or replace its URL with another image URL.
